## Trạng thái hiện tại

- Thư mục dự án rỗng (chỉ có git init, README mặc định).
- Chưa có tài liệu, dữ liệu, mô hình nào.
- Trạng thái: **PROPOSED** — toàn bộ kế hoạch chưa được xác nhận bởi người dùng.

## Quy ước trạng thái

`VERIFIED` / `PROPOSED` / `HYPOTHESIS` / `UNKNOWN` / `BLOCKED` / `DECISION_REQUIRED`.

## Cập nhật trạng thái
