Đã hoàn thành Conceptual Framework với kiến trúc 3 lớp:
1. **Wave Layer** - sóng tài chính từ Brunnermeier (2009), Cetorelli-Goldberg (2011), Popov-Udell (2010)
2. **Network Layer** - mạng tài chính từ Jackson-Pernoud (2021), Eisenberg-Noe
3. **Sandpile Layer** - mô hình đống cát từ Luna-Zanforlin IMF 2025 - CRITICAL validation cho IFWST

Điểm độc đáo: Tích hợp sandpile/Abelian model vào hệ thống tài chính - cùng phương pháp với IMF WP/25/041

**Why:** Đây là lõi kiến trúc lý thuyết cho toàn bộ nghiên cứu. Khung này trả lời câu hỏi nghiên cứu trung tâm: "Có thể xây dựng mô hình tích hợp sóng tài chính + mạng + đống cát để dự báo khủng hoảng không?"

**How to apply:** Chuyển sang giai đoạn 3 (Đặc tả mô hình) hoặc giao task cho subagent để triển khai các bước tiếp theo.
